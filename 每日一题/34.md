# 1910. 删除一个字符串中所有出现的给定子字符串
# 考察 
1 s.find()返回起始下标  
2 s.erase(起始下标,长度)  
```c++
class Solution {
public:
    string removeOccurrences(string s, string part) {
        while(1){
            if(s.find(part)!=string::npos) s.erase(s.find(part),part.size());
            else return s;
        }
    }
};
```
