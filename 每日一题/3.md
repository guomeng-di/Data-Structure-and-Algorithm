# 题目:3120. 统计特殊字母的数量 I

## 分析: 

1map 映射

2set功能:去重,排序,查找

3此题涉及某个字母可能出现多次.但只统计一次,而set不知道对应的值,故改用vector

## 代码:

```c++
class Solution {
public:
    int numberOfSpecialChars(string word) {
        vector<int> st_small(26,0);
        vector<int> st_big(26,0);
        int ans=0;
        for(int i=0;i<word.size();i++){
            if(word[i]>='a'&&word[i]<='z'){//小写
                if(st_small[ word[i]-'a' ]==0&&st_big[word[i]-'a']==1){
                    ans++;
                    st_small[ word[i]-'a' ]++;
                }
                else if(st_small[ word[i]-'a' ]==0&&st_big[word[i]-'a']==0)
                st_small[ word[i]-'a' ]++;
            }else{
                if(st_big[ word[i]-'A' ]==0&&st_small[word[i]-'A']==1){
                    ans++;
                    st_big[ word[i]-'A' ]++;
                }
                else if(st_big[ word[i]-'A' ]==0&&st_small[word[i]-'A']==0)
                st_big[ word[i]-'A' ]++;
            }
        }
        return ans;
    }
};
```
