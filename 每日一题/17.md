# 396. 旋转函数

n=10^5

## 初次代码: 时间复杂度 o(n^2)

```c++
class Solution {
public:
    int maxRotateFunction(vector<int>& nums) {
        int ans=-INT_MAX;
        int n=nums.size();
        for(int k=0;k<n;k++){
            int sum=0;
            for(int i=0;i<n;i++){
                sum+=nums[i]*((k+i)%n);
            }
            ans=max(ans,sum);
        }
        return ans;
    }
};
```
## 优化: 时间复杂度 o(n)
在初次写代码时,我们就看出规律:

(n=nums.size()   total=nums[i],i=1到i=n-1求和)

F(k)=nums[i]*((k+1)%n),i=1到i=n-1求和

推理发现,每次k++,大部分数都由原来的 *m 变成 *(m+1)->即+total

唯有上一次的结尾的数变成了0 

得出公式:

F(k)=F(k-1)+total-n*nums[n-k];

```c++
class Solution {
public:
    int maxRotateFunction(vector<int>& nums) {
        vector<int> F;
        int n=nums.size();
        int total=0;//nums[i]求和
        int sum=0;
        for(int i=0;i<n;i++){
            total+=nums[i];
            sum+=nums[i]*i;
        }
F.push_back(sum);
for(int k=1;k<n;k++){
    int q=F[k-1]+total-n*nums[n-k];
    F.push_back(q);
}
sort(F.begin(),F.end());

return F[n-1];

    }
};
```
