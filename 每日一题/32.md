# 1887. 使数组元素相等的减少操作次数
## 考察:
1 元素去重:sort+unique+erase  
2 统计元素出现次数 unordered_map  
```c++
class Solution {
public:
    int reductionOperations(vector<int>& nums) {
        //1排序
        sort(nums.begin(),nums.end());
        //2统计每个数出现几次
        unordered_map<int,int> mp;
        for(int i=0;i<nums.size();i++){
            mp[nums[i]]++;
        }
        //3位于第几级
        auto last=unique(nums.begin(),nums.end());//unique
        nums.erase(last,nums.end());//erase
        //4计算
        int sum=0;
        for(int i=0;i<nums.size();i++){
            sum+=(i-0)*mp[nums[i]];
        }
        return sum;
    }
};
//每个数值的数量 × 它需要下降的层数
//1每个数出现了几次
//2它位于第几级
```
