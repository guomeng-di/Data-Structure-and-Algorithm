# 初次尝试:
# 算法:
暴力双循环
```c++
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        //暴力
        vector<int> ans;
        for(int i=0;i<nums.size();i++){
            for(int j=i+1;j<nums.size();j++){
                if(nums[i]+nums[j]==target)
                  ans.push_back(i),ans.push_back(j);
            }
        }
        return ans;
    }
};
```
# 第二次自我尝试(优化):
## 思路:
不妨先排序(sort),排序后思路是:  
从两边往中间逐渐缩小范围  
nums[left]+nums[right] ? target  
==-> 找到了  
 > ->   当前和太大了,所以要减小,而nums[left]是可能的答案(left~right)的范围中最小的,故减小nums[right],即right--  
同理,< ->left++  
## 解题过程:
难点转化为:  
返回的是数组下标,可是排序了,下标改变  
引入:**pair<val, idx>**，默认由第一个元素（数值）从小到大排序  
```c++
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {

        vector<int> ans;
        vector<pair<int,int>> arr;
        for(int i=0;i<nums.size();i++){
            arr.emplace_back(nums[i],i);
        }
        sort(arr.begin(),arr.end());
        //sort(nums.begin(),nums.end());
        int left=0,right=nums.size()-1;
        while(left<right){
            if(arr[left].first+arr[right].first==target){
                ans.push_back(arr[left].second);
                ans.push_back(arr[right].second);
                return ans;
            }
            else if(arr[left].first+arr[right].first>target){
                right--;
            }
            else if(arr[left].first+arr[right].first<target){
                left++;
            }
        }
        return ans;
    }
};
```
# 题解
## 方法:哈希表
因为哈希表找一个数的复杂程度是o(1),所以把每个数存入哈希表,再遍历寻找(2遍哈希表)
优化:
边存边找->对每个数,先找再存
```c++
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        //法三:哈希表
        //哈希表存原数值,原下标
        //找有没有符合相减后
        unordered_map<int,int> mp;
        for(int i=0;i<nums.size();i++){
            if(mp.find(target-nums[i])!=mp.end()){
                return {i,mp[target-nums[i]]};
            }
            mp[nums[i]]=i;
        }
        return {};
    }
};
```
