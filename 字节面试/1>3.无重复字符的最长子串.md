# 题目内容:
给定一个字符串s，请你找出其中不含有重复字符的最长子串的长度
# 思考:
不含重复字符--哈希表存字符状态
最长子串--滑动窗口
# 思路:
left从0开始,right遍历
对每一个字符,哈希表存状态,未出现过则第一次存入,出现过则须窗口left不断右移并hash--,直到窗口内第一次出现
每次遍历结果均取最大值 ans=max(ans,right-left+1)
# 代码实现:
```c++
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        int ans=0;
        int left=0,right=1;
        unordered_map<char,int> mp;
        //mp[s[left]]=1;
        if(s.size()==0) return 0;
        else if(s.size()==1) return 1;
        else mp[s[left]]=1;
        for(right=1;right<s.size();right++){
            while(mp.find(s[right])!=mp.end()&&left<s.size()){
                //mp[s[left]]--;
                mp.erase(s[left]);
                left++;
            }
            mp[s[right]]++;
            ans=max(ans,right-left+1);
        }
        return ans;
    }
};
```

# 优化2:
字符都是标准ASCII (0~127)，ASCII数组替代哈希表,数组无哈希冲突、开销更低
## 我的代码:
```c++
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        int ans=0;
        int left=0,right=0;
        vector<int> pos(128,-1);
        if(s.size()==0) return 0;
        else if(s.size()==1) return 1;
        else pos[s[left]]=0;
        for(right=1;right<s.size();right++){
            if(pos[s[right]]!=-1&&pos[s[right]]>=left){
                left=pos[s[right]]+1;
            }
            pos[s[right]]=right;
            ans=max(ans,right-left+1);
        }
        return ans;
    }
};
```
